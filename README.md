# 🧠 Doc-Mind

**AI-powered document chatbot built with Java, Spring Boot & Spring AI.**

Doc-Mind is a project that aims to let users upload documents and PDFs and interact with them through an AI-powered chatbot.

The project will use **RAG (Retrieval-Augmented Generation)** to retrieve relevant information from uploaded documents and generate context-aware answers.

## 🚀 Tech Stack

* Java
* Spring Boot
* Spring AI
* PostgreSQL
* pgvector
* OpenAI
* RAG

## 🛠️ Current Status

🚧 **Under Development**

Currently setting up the backend, database, Spring AI integration, and vector store. More features will be added step by step.

## 🎯 Planned Features

* 📄 PDF & document upload
* 🔍 Document processing & text extraction
* 🧩 RAG-based information retrieval
* 💬 AI-powered document chat
* 🧠 Vector embeddings & similarity search
* 🔐 User authentication
* 📚 Multiple document support
